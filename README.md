# Fanyi-Lite · 简净翻译

适用于 Microsoft Edge 的百度翻译界面增强扩展。它精简文本、文档和图片三个翻译工作区，收起部分推广内容，统一编辑器、弹出菜单、历史记录和收藏夹的样式。翻译、AI 助手、词典与文件上传仍由百度翻译提供。本项目由独立开发者维护。

## 本地安装

1. 从 Releases 下载最新的 `Fanyi-Lite-*.zip`，解压到单独的文件夹。
2. 在 Edge 打开 `edge://extensions`，开启开发人员模式。
3. 选择「加载解压缩的扩展」，选中 `manifest.json` 所在的文件夹。
4. 打开或刷新百度翻译。右侧的主题按钮可以切换浅色和深色模式。

收藏需要登录百度账号。未收藏时，单击星标添加到系统分组，长按可选择分组。页面上的选项以百度翻译实际提供的功能为准。
